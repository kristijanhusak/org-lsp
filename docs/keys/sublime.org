The package binds keys by preset, picked with ~org_keys~ in its settings
(/Preferences: LSP-org Settings/):

- ~"emacs"~, the default: Emacs's keys in Org files. ~Ctrl+C Ctrl+T~ changes
  the TODO state, ~Shift~ and the arrows change the priority, the timestamp
  under the cursor or the TODO state, ~Ctrl+C Ctrl+S~ schedules,
  ~Ctrl+C Ctrl+W~ refiles, ~Ctrl+C c~ captures, ~Ctrl+C a~ opens the agenda
  menu, ~Tab~ and ~Shift+Tab~ cycle folds as Org's TAB and S-TAB do. In a
  capture buffer, ~Ctrl+C Ctrl+C~ files the entry.
- ~"vim"~, for Vintage and NeoVintageous: the Neovim plugin's keys that do
  not start with a plain letter or the leader, in command mode (~Tab~,
  ~Ctrl+Space~, ~Ctrl+A~ …). Bind the others yourself.
- ~"custom"~: none; bind your own.

The keys are bound in Org files and the agenda only, where ~Ctrl+C~ does not
copy. The agenda has the same keys with either preset, and in every
editor: Emacs's agenda keys (~f~, ~b~, ~.~, ~t~, ~+~, ~Enter~, ~Ctrl+C Ctrl+S~ …),
with ~Shift+J~ for a date and the views under ~v~ (~v d~, ~v w~), so that
Vintage and NeoVintageous keep their motions; with ~"vim"~, ~$~ stays the
end of the line, not archiving. ~q~ closes the agenda and ~g ?~ lists its
keys.

/Org: Show the keys/ lists the keys bound in the view at hand, and the
Command Palette lists every command under /Org:/. [[file:../sublime.org][sublime.org]] says how
to install and set up the package.

* Your own keys

Any command can be bound in your own key bindings (/Preferences › Key
Bindings/) with ~org_lsp_run~, which tells the server where the cursor is:

#+begin_src json
{ "keys": ["alt+t"], "command": "org_lsp_run", "args": {"command": "org.todo"},
  "context": [{"key": "selector", "operand": "text.org"}] }
#+end_src

~count~ passes Emacs's prefix argument: ~C-u~ is 4, ~C-u C-u~ 16,
~C-u C-u C-u~ 64. For example, the images of the whole file, and none:

#+begin_src json
{ "keys": ["ctrl+c", "ctrl+x", "v"], "command": "org_lsp_run", "args": {"command": "org.link.preview", "count": 16},
  "context": [{"key": "selector", "operand": "text.org"}] },
{ "keys": ["ctrl+c", "ctrl+x", "shift+v"], "command": "org_lsp_run", "args": {"command": "org.link.preview", "count": 64},
  "context": [{"key": "selector", "operand": "text.org"}] }
#+end_src

With ~"org_keys": "custom"~ the package binds none, and yours are the only
ones.
